# First-Person Shooter Game

## About the Game

This is a first-person shooter (FPS) game developed using Unity. The goal is to survive five waves of enemies by shooting them, managing your health, and collecting health packs.

Players must defeat all enemies in each wave to progress. Survive all five waves to win the game!

## Features

- **First-Person Movement:** Move, jump, and look around from a first-person perspective.
- **Shooting System:** Shoot enemies with a gun featuring recoil effects.
- **Enemy AI:** Enemies move toward the player and attack when they are close enough.
- **Health System:** Track player health and take damage from enemies.
- **Health Packs:** Collect health packs to restore health.
- **Wave System:** Fight through five waves of enemies.
- **Camera Effects:** Experience camera shake when taking damage and a death animation when defeated.
- **Win and Game Over Screens:** See your result and restart the game after a round ends.

## Controls

| Key / Input | Action |
|---|---|
| W / A / S / D | Move |
| Mouse | Look around |
| Space | Jump |
| Left Mouse Button | Shoot |

## Objective

Defeat all enemies across five waves without losing all your health. If your health reaches zero, the game ends. Try again and see if you can complete every wave!

## Built With

- Unity
- C#
- Unity Character Controller
- Unity UI / TextMeshPro

## How to Play

1. Launch the game.
2. Use the keyboard and mouse to move and aim.
3. Shoot enemies before they defeat you.
4. Collect health packs when needed.
5. Survive all five waves to win.
